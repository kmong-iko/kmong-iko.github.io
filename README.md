# Katelyn Ong-Iko | Interactive Portfolio

An interactive personal portfolio showcasing my projects, creative work, and journey as a Computer Science student specializing in Software Engineering.

💛 **Live Website:** [kmong-iko.github.io](https://kmong-iko.github.io/)

## Overview

This portfolio combines my interests in technology and art through an illustrated, interactive web experience. Featuring original character artwork, playful animations, and custom interactions, it serves as a space to showcase my technical projects, design work, and creative background.

The website was designed with a focus on visual storytelling, user experience, and frontend experimentation.

## Features

- **Interactive Character:** A layered illustrated avatar with cursor-based eye tracking and animated expressions.
- **Custom Animations:** Animated typing, character movements, and interactive visual elements.
- **Draggable Objects:** Interactive mug with physics-based movement.
- **Light & Dark Mode:** Theme switching with preserved artwork appearance.
- **Sound Effects:** Subtle audio feedback for selected interactions.
- **Responsive Design:** Layout adjustments for desktop and mobile screens.
- **Interactive Navigation:** Dedicated sections for Home, Workfolio, and Contact.
